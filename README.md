# Student Management System

A C++ command-line application to manage student records effectively. Developed using Object-Oriented Programming (OOP) principles, vectors, and modular design.

## Features
- Add new student records (ID, Name, GPA)
- View all existing student details in a formatted table
- Interactive CLI menu interface
